# دیوان

بک‌اند اکنون فقط MySQL/MariaDB استفاده می‌کند و برای دیتابیس `divanhaj_db` روی همان هاست تنظیم شده است. SQLite اپ برای کش و پیش‌نویس باقی می‌ماند. رمز اتصال فقط در `.env` خصوصی بک‌اند است؛ اتصال و خواندن اطلاعات روی هاست تأیید شدند.

بک‌اند مستقل کنار اپ در `backend/` به Laravel 13 منتقل شده و پنل فارسی آن بازطراحی شده است. مسیر خواندن اپ قدیمی حفظ شده؛ مدیریت اپ جدید و پنل توکن Bearer دارند. [راهنمای نصب روی هاست](backend/DEPLOYMENT.md). پنل روی سایت اصلی نصب شده و ورود، فهرست‌ها، تصاویر دسته‌ها و مطالعهٔ مطلب بررسی شده‌اند. ایجاد/ویرایش/حذف زنده هنوز آزمایش نشده‌اند.

API قدیمی روی HTTP بدون توکن با درخواست اندروید بررسی شد: ۳۲ دسته، ۳۲۱ مطلب و جزئیات دریافت می‌شوند. مقدار صفر در queryها نیز روی هاست اصلاح شد. ویرایشگر پنل به CKEditor فارسی با امکانات پنل قبلی تغییر کرده، روی هاست نصب شده و حالت HTML، جدول و پیش‌نمایش آن در Chrome زنده بررسی شدند.

اپ Flutter برای مطالعهٔ عمومی دیوان در Android و وب است. مدیریت محتوا فقط از پنل وب انجام می‌شود؛ اپ موبایل ورود مدیر و ابزار ویرایش ندارد.

## اجرای وب با API اصلی

<div dir="ltr" align="left">

```sh
flutter pub get
dart run sqflite_common_ffi_web:setup
flutter build web --debug --no-wasm-dry-run --no-web-resources-cdn
```

</div>

برنامه به‌صورت مستقیم از `http://divanhajghasem.ir/api.php`، همان API نسخهٔ Android، استفاده می‌کند. برای اجرای خروجی وب باید آن را روی میزبان وب خودتان قرار دهید؛ اگر سرور API هدر CORS نداشته باشد، مرورگر درخواست مستقیم را مسدود می‌کند و نسخهٔ Android همچنان بدون این محدودیت کار می‌کند. SQLite وب در IndexedDB ذخیره می‌شود؛ پاک‌کردن داده‌های سایت یا استفاده از مرورگر دیگر، نوشته‌های این مرورگر را در دسترس قرار نمی‌دهد.

برای پیش‌نمایش توسعه‌ای در VS Code، تنظیم `دیوان (web با CORS توسعه‌ای)` در `.vscode/launch.json` مرورگر Chrome را با `--disable-web-security` باز می‌کند. این فقط برای توسعهٔ محلی است و نباید برای استفادهٔ عمومی یا انتشار به کار رود.

کد PHP در `backend/` کنار این پروژه است و سرور یا proxy محلی اجرا نمی‌شود. اپ محتوای عمومی را از API می‌خواند و برای مطالعهٔ آفلاین cache می‌کند. ورود، ایجاد، ویرایش و حذف فقط در پنل وب انجام می‌شود.

## ادامه کار در Codex

بسته را باز کنید و پوشه `hajqasem_app` را به‌عنوان پروژه در Codex یا افزونه Codex داخل IDE انتخاب کنید. دستورهای ادامه کار در `AGENTS.md` قرار دارد و شرح تصمیم‌ها در `docs/PROJECT_CONTEXT.md` آمده است. این بسته فایل پروژه است؛ به نشست یا مخزن موجود شما در Codex به‌طور خودکار متصل نشده است.

## راه‌اندازی

Flutter دارای Dart 3.10 یا جدیدتر لازم است؛ محیط بررسی Flutter 3.41.9 است. برای Android، SDK اندروید و گوشی یا شبیه‌ساز لازم است. فایل‌های بومی Android و وب اکنون تولید شده‌اند. از داخل پوشه پروژه اجرا کنید:

<div dir="ltr" align="left">

```sh

```

</div>

نام نمایشی برنامه «دیوان» است؛ شناسه و امضای انتشار پیش از انتشار عمومی نهایی شوند.

## امکانات نوشته‌شده

- دریافت دسته‌ها و مطالب از `http://divanhajghasem.ir/api.php` و متن سه صفحهٔ معرفی از `pages.php`
- نمایش عنوان فرعی و HTML فارسی، جستجو و تنظیم اندازه متن دیوان
- نمایش فوری کش موجود و به‌روزرسانی خودکار دسته یا فهرست مطلب از API هنگام باز کردن آن
- سه بخش خانه، دسته‌بندی‌ها و تنظیمات؛ جستجو در عنوان و متن و مطالعهٔ آفلاین مطالب بازشده
- خانه شامل پیوندهای «سخن اول»، «سخن آخر» و «تماس با ما» است؛ متن هر سه از سرور می‌آید و برای مطالعهٔ آفلاین cache می‌شود
- ویرایش صفحه‌های معرفی در پنل و با همان ویرایشگر CKEditor انجام می‌شود
- حفظ محل مطالعه و تنظیم اندازهٔ متن برای همهٔ کاربران
- چیدمان دسته‌های تصویری متناسب با عرض صفحه و اندازهٔ متن
- فونت Vazirmatn همراه فایل‌های مجوز OFL

محتوای عمومی از API اصلی می‌آید؛ هیچ دسته یا مطلب پیش‌فرضی ساخته نمی‌شود. اگر اتصال هنگام باز کردن فهرست برقرار نباشد، کش قبلی نمایش داده می‌شود. اگر هنوز کشی وجود نداشته باشد، خطا و تلاش مجدد نمایش داده می‌شود. افزودن دسته از داخل اپ وجود ندارد.

SQLite نسخهٔ ۶ پیش‌نویس‌ها، Delta ویرایشگر Quill، کش و نتیجهٔ نامشخص درخواست‌های ارسال‌شده را نگه می‌دارد. جدول آزمایشی `local_posts` برای سازگاری schema باقی است و در مسیر فعال خواندن یا نوشتن استفاده نمی‌شود. برای ایجاد مطلب باید دسته‌ای موجود در سایت انتخاب شود. پاسخ مطالب سایت، متن کامل را برای مطالعهٔ آفلاین cache می‌کند؛ تصاویر ممکن است دوباره به شبکه نیاز داشته باشند. تازه‌سازی سرور متن بازشده یا پیش‌نویس در حال ویرایش را تغییر نمی‌دهد.

## ذخیره و پشتیبان

هر تغییر پیش‌نویس همراه نسخهٔ قبلی و outbox در یک تراکنش ثبت می‌شود. خطای ذخیره صفحه را نمی‌بندد. ارسال فقط با دکمهٔ کاربر انجام می‌شود. تأیید همان revision، cache و حذف پیش‌نویس را اتمیک ثبت می‌کند؛ تغییر تازه‌تر باقی می‌ماند. رمز و توکن در SQLite ذخیره نمی‌شوند؛ توکن فقط در حافظهٔ اپ است.

در قطع ارتباط پس از POST، «بررسی نتیجهٔ ارسال/حذف» فقط از API می‌خواند و POST را تکرار نمی‌کند؛ وضعیت تا بازگشایی برنامه هم حفظ می‌شود. اگر نتیجه روشن نشد، تطبیق دستی با سرور لازم است؛ اپ درخواست را خودکار تکرار نمی‌کند. PHP فعلی شناسهٔ درخواست تکرارناپذیر یا کنترل اتمیک تعارض ندارد. تغییر نسخهٔ پایه پیش از ارسال شناسایی می‌شود، اما رقابت هم‌زمان روی سرور تضمین کامل ندارد.

endpoint نوشتن، عنوان فرعی را الزامی می‌داند. تغییر عنوان/دسته HTML را دقیقاً حفظ می‌کند. ویرایش بدنه با Flutter Quill انجام می‌شود؛ Delta پیش‌نویس روی دستگاه و HTML سازگار با PHP هنگام ارسال استفاده می‌شود. تبدیل HTML قدیمی به قالب‌های قابل ویرایش با تأیید کاربر انجام می‌شود و نسخهٔ پیشین قابل بازیابی است.

«روی گوشی ذخیره شد» به معنای پشتیبان بیرون از گوشی نیست. پاک کردن داده برنامه یا حذف برنامه می‌تواند پایگاه داده محلی را پاک کند. پیش از استفاده اصلی، خروجی پشتیبان و بازیابی یا سرور احراز هویت‌شده باید اضافه و آزموده شود. موقع بستن اجباری فرآیند در لحظه تایپ، آخرین تغییر در حال ثبت ممکن است هنوز کامل نشده باشد؛ معیار پذیرش بازیابی آخرین تراکنش موفق است.

## مخزن‌ها و API توکن

- Flutter: https://github.com/mehdi31075/divanhajghasem_flutter
- PHP: https://github.com/mehdi31075/divanhajghasem_backend

`divan.code-workspace` را باز کنید تا Flutter و PHP با دو مخزن مستقل در همین ادیتور دیده شوند. در clone تازه، مخزن PHP را داخل `backend/` clone کنید؛ این پوشه از Git پروژهٔ Flutter کنار گذاشته شده است.

راهنمای نصب سازگار با پنل و دیتابیس قدیمی: [backend/README.md](backend/README.md). پس از نصب فایل‌ها و migration روی هاست و فعال بودن HTTPS:

<div dir="ltr" align="left">

```sh
flutter run -d chrome --wasm --no-web-resources-cdn \
  --dart-define=DIVAN_API_URL=https://divanhajghasem.ir/mobile-api.php
```

</div>

API جدید CORS دارد و توکن با هدر Bearer ارسال می‌شود؛ Chrome برای این مسیر به خاموش کردن امنیت نیاز ندارد. آدرس پیش‌فرض خواندن هنوز API فعلی است تا انتشار بک‌اند، مطالعهٔ عمومی را قطع نکند. پنل جدید نیز توکن مصرف می‌کند؛ فرم‌های کوکی بازنشسته شده‌اند. API عمومی نسخهٔ اندروید قدیمی بدون توکن حفظ شده است.
