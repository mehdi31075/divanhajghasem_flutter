# مهاجرت به Laravel — ۲۰۲۶/۱۰/۰۷

بک‌اند `backend/` اکنون Laravel 13 با پنل فارسی و واکنش‌گراست. URL عمومی `api.php` و قرارداد JSON اپ Android قدیمی بدون توکن حفظ شده‌اند؛ خود فایل PHP قدیمی جای خود را به route لاراول داده است. پنل و Flutter با قرارداد `mobile-api.php?action=...` و توکن Bearer کار می‌کنند. رمزهای فعلی معتبرند؛ تغییر رمز از bcrypt استفاده می‌کند.

مدیریت Flutter پیش‌فرض HTTPS است؛ endpoint خواندن عمومی تغییری نکرده. راهنمای استقرار کامل در `backend/DEPLOYMENT.md` است. انتقال روی هاست هنوز انجام نشده؛ PHP 8.3+ و گواهی TLS معتبر لازم است. گواهی فعلی سایت در بررسی امروز منقضی بود. فصل‌های بعدی که از فایل api.php دست‌نخورده یا PHP قدیمی می‌گویند، وضعیت تاریخی پیش از Laravel را شرح می‌دهند.

# اصلاح دامنهٔ سازگاری — ۲۰۲۶/۱۰/۰۶

کاربر روشن کرد اپ Android موجود صرفاً خواندنی و بدون توکن است و تنها این اپ باید سازگار بماند. پنل قبلی می‌تواند تغییر کند. اکنون پنل نیز با API Bearer یکپارچه شده؛ ورودی‌های PHP رابط جدید را باز می‌کنند و POST کوکی/فرم‌های مستقیم public با ۴۱۰ بازنشسته‌اند. api.php عمومی عیناً حفظ شده، migration همچنان همان دو جدول مستقل auth است و نوشته‌های توکن در API قدیمی خوانده می‌شوند. هنوز انتشار روی هاست انجام نشده است.

# به‌روزرسانی ۲۰۲۶/۱۰/۰۶ — توکن و GitHub

کاربر اکنون تغییر بک‌اند را خواسته است: ورود و ایجاد/ویرایش با توکن در کنار قرارداد قدیمی، بدون از کار افتادن پنل و API فعلی. کد PHP پیوست در backend/ قرار گرفته و مخزن مستقل دارد. فایل‌های PHP قدیمی تغییر نکرده‌اند. API جدید mobile-api.php و دو جدول auth مستقل اضافه شده‌اند. Flutter ورود واقعی توکن را به‌صورت پیش‌فرض مصرف می‌کند و حالت کوکی فقط تنظیم صریح سازگاری است. رمز و توکن در SQLite ذخیره نمی‌شوند. نصب روی هاست و اجرای migration انجام نشده؛ کد و دستور نصب آماده‌اند.
